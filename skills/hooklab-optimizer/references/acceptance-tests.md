# Optimizer Acceptance Tests

## Test 1 — Strong reach, weak saves
Input: reach 20,000; saves 80; DMs 3; hook is Silent Killer.
Expected: Calculate 0.4% save rate and 0.15 DM/1,000. Recommend reducing overpromise or increasing utility, not merely making the hook more shocking.

## Test 2 — Strong saves, weak DMs
Input: reach 10,000; saves 350; DMs 2.
Expected: 3.5% save rate, 0.2 DM/1,000. Diagnose CTA/offer bridge, propose a hook that naturally leads to a concrete deliverable.

## Test 3 — No baseline
Input: one post only.
Expected: Make calculations but label diagnosis provisional; do not claim statistical certainty.

## Test 4 — Formula fatigue
Input: last four posts all used Crazy Math and performance declined.
Expected: Retire or pause Crazy Math and test a different mechanism tied to the same audience tension.
