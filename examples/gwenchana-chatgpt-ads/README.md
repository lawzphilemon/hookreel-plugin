# Example: Gwenchana Digital · ChatGPT Ads teaser

A complete brand and video for the template: an 8-scene English teaser for a free guide on tracking WhatsApp clicks from ChatGPT Ads in GA4.

- `brand.json`: dark theme (obsidian background, citron accent, Montserrat).
- `videos/teaser.json`: every scene type the teaser uses, with cues and on-screen sources.

To try it, copy both into a studio made from `template/`, then `npm install` and `npm run dev`.

Not included: the logo file (`logo` is `null`, so the brand name shows as text), the voiceover recording, and the music track. The numbers were checked on 12 October 2026 and will go stale; recheck them before reusing.
